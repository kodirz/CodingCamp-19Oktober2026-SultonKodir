# ⚡ Quick Start Guide

## 🚀 Immediate Actions

### 1. Test Locally (5 minutes)
```
1. Open index.html in your browser
2. Test all features:
   ✓ Clock is updating
   ✓ Add a task
   ✓ Start the timer
   ✓ Add a quick link
   ✓ Toggle dark mode
   ✓ Refresh page - data should persist
```

### 2. GitHub Setup (10 minutes)
```
1. Open GitHub Desktop
2. File → Add Local Repository
3. Select this folder: C:\Users\PONGO\Documents\camp
4. Click "Create Repository"
5. Name: CodingCamp-24August26-[yourname]
6. Commit: "Initial commit - Life Dashboard"
7. Click "Publish repository"
8. Make it PUBLIC ⚠️
```

### 3. Deploy to GitHub Pages (5 minutes)
```
1. Go to your repo on github.com
2. Settings → Pages
3. Source: main branch, / (root)
4. Click Save
5. Wait 2 minutes
6. Your site URL will appear
```

### 4. Submit (2 minutes)
```
When form opens on Wednesday, submit:
1. AWS Builder ID (from Kiro account)
2. GitHub repo URL
3. Deployed website URL

Example URLs:
Repo: https://github.com/username/CodingCamp-24August26-yourname
Site: https://username.github.io/CodingCamp-24August26-yourname/
```

## ⚠️ Common Issues & Quick Fixes

### Issue: GitHub Desktop says "not a git repository"
**Fix**: Click "Create a repository" instead

### Issue: Can't find .kiro folder in GitHub
**Fix**: Check .gitignore doesn't block it (it shouldn't)

### Issue: GitHub Pages shows 404
**Fix**: Wait 3-5 minutes, clear cache, check repo is public

### Issue: Features not working on deployed site
**Fix**: Open browser console (F12) to check for errors
